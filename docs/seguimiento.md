# Seguimiento del proyecto - Servi Taxi

## 1. Información general

**Proyecto:** Servi Taxi  
**Tecnología:** Flutter y Dart  
**Control de versiones:** Git y GitHub  
**Integrantes:** Lizeth Nallely López García & Abelardo Ortiz Ortiz

**Objetivo:** Desarrollar una aplicación de transporte local que permita consultar servicios, seleccionar un recorrido, obtener una cotización y simular la confirmación de un viaje.
